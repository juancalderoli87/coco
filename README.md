# COCO Concrete Company

Repositorio del sitio web de COCO Concrete Company — diseño en concreto UHPC (bachas, mesadas, mobiliario), desde Paraguay.

## Estructura

```
contenido/
  fotos/    Fotos de productos, proyectos, taller, equipo
  pdf/      Catálogos, fichas técnicas, presentaciones
  logos/    Logos y elementos de marca
  textos/   Copys, descripciones, bios, notas (.md / .txt / .docx)
  otros/    Cualquier otro material (videos, referencias, etc.)
```

Subí todo el material en `contenido/`. Con eso se arma el sitio.
